Site search requirements

Part of the Northwind Outfitters analytics requirements.

Requirements

  • Track every internal search with the search keyword (lower-cased) and the number of results.
  • Track zero-result searches as a separate event so the merchandising team can fix them.
  • Track the search type: typed search, autocomplete suggestion click, or recent search.
  • Track clicks on search results with the clicked position and product SKU.
  • Track search filter usage on the results page (filter name and value).

Success metrics

Search usage rate, search exit rate, zero-result rate, and search-to-order conversion.
